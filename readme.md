# Evolve

Evolve — приложение для управления задачами, которое помогает планировать дела,
отслеживать их выполнение и постепенно развивать привычку доводить задачи до
результата.

Проект создан на Django и находится в активной разработке. В будущем планируется
добавить уведомления, геймификацию и фоновые задачи с использованием Celery и
Redis.

## Возможности

Сейчас реализовано:

- регистрация и вход пользователей;
- кастомная модель пользователя;
- уникальные email и никнейм;
- профиль пользователя;
- загрузка и отображение аватарки;
- автоматический fallback-аватар с первой буквой никнейма;
- создание задач;
- описание и дедлайн задачи;
- изменение статуса задачи;
- просмотр списка текущих задач;
- история выполненных задач;
- отдельная страница с подробностями задачи;
- пагинация списка задач.
- CRUD для категорий задач
- фильтр задач по категориям
- получения опыта и уровня за выполнение задач

Доступные статусы задачи:

- `Не начата`;
- `В процессе`;
- `Выполнена`;
- `Провалена`.

## Технологии

- Python;
- Django 6.1;
- SQLite;
- Pillow для обработки изображений;
- Django Debug Toolbar для разработки;
- python-dotenv для загрузки переменных окружения;
- HTML и CSS.


## Установка и запуск

### 1. Клонирование проекта

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd Evolve
```

### 2. Создание виртуального окружения

Windows PowerShell:

```powershell
py -m venv venv
.\venv\Scripts\Activate.ps1
```

Linux/macOS:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создай файл `.env` в корне проекта на основе `.env.example`:

```env
SECRET_KEY='your-secret-key'
```

### 5. Применение миграций

```bash
python manage.py migrate
```

### 6. Создание администратора

```bash
python manage.py createsuperuser
```

### 7. Запуск сервера разработки

```bash
python manage.py runserver
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:8000/
```

Корневой URL перенаправляет пользователя на страницу входа или список задач,
если пользователь уже авторизован.

## Основные маршруты

| Раздел | URL |
| --- | --- |
| Вход | `/users/login/` |
| Регистрация | `/users/register/` |
| Профиль | `/users/profile/` |
| Список задач | `/tasks/` |
| Создание задачи | `/tasks/create/` |
| История задач | `/tasks/history/` |
| Админ-панель | `/admin/` |

## Работа с медиафайлами

Аватарки пользователей сохраняются в каталоге `media/avatars/`.

В режиме разработки медиафайлы раздаются Django через настройки проекта. Для
production-среды рекомендуется использовать отдельное хранилище или веб-сервер
для медиафайлов.
